# Python Multi Tool App

A beginner Python multi-tool application combining a calculator and number analyzer.

---

# Version 1
Features:
- Calculator
- Number Analyzer
- Single Combined Menu

Concepts Used:
- Functions
- Loops
- Conditions
- Menu System

---

# Version 2
Major Improvements:
- Nested Menus
- Separate Calculator Section
- Separate Number Analyzer Section
- Back Option

Concepts Added:
- Nested Loops
- Better Program Organization
- Multi-Level Menu Systems

# Included Tools

## Calculator
- Add
- Subtract
- Multiply
- Divide
- Square
- Power

## Number Analyzer
- Even / Odd
- Prime Check
- Palindrome Check
- Armstrong Check
- Factorial
- Digit Sum
- Largest Digit
- Smallest Digit
